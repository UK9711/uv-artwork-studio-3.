UV Artwork Studio - Integrated version

Run START_UV_STUDIO.bat or open Command Prompt in this folder and run:
python -m streamlit run app.py

Upload customer demo images, enter your OpenAI API key, generate the flat artwork, and the app will automatically crop transparent margins. Optionally create a silhouette that includes the entire visible logo, including its white outline. Download individual PNGs or a ZIP batch.

The crop removes transparent exterior margins only. It does not remove white artwork. Review AI-generated text and details before production.
